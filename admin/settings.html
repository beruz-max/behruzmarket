Security Notice

This admin panel uses client-side authentication for demo purposes only. Credentials are checked in JavaScript and session is stored in sessionStorage.

For production:
• Implement server-side authentication
• Hash passwords (bcrypt / argon2)
• Use secure HTTP-only cookies / JWT
• Protect all admin API endpoints
• Never store passwords in frontend code
